## 💻 Running Locally

### Option 1: Open Directly
Simply open `index.html` in any web browser!

### Option 2: Run with Local Server
```bash
# Using Node / npx
npx serve -l 3000

# Or with Python
python -m http.server 3000
```
Then visit [http://localhost:3000](http://localhost:3000).

## 🚀 Deploying to Vercel (1-Click / CLI)

To deploy your portfolio live to your own Vercel URL (e.g. `gagan-portfolio.vercel.app`):

```bash
cd C:\Users\gagan\portfolio
npx vercel --prod
```

When prompted:
1. Confirm the project directory (`./`).
2. Give your project a name (e.g. `gagan-portfolio`).
3. Vercel will upload and give you a live production URL!
